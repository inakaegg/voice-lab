# 連想経路確認CLI（rensou_dict）の図解

更新日: 2026-08-08

入力の単語や文から動物へ至る経路を、辞書ごとに分けて表示するローカル確認用CLI。

## 使い方

```sh
./tools/rensou_dict.sh "喉が渇いた"
./tools/rensou_dict.sh "にゃーにゃー" --top-k 3
```

## 前提

- リポジトリ外のモデル・辞書資産（ConceptNet/WordNetのSQLite、embedding venvとONNXモデル）を使う。置き場所が既定と違う場合は `ZOOVOICE_MODELS_DIR` で指定する。
- worktree内の `tmp/embedding-pilot/bin/zoovoice`（Go本体のビルド）と `tmp/embedding-trial/onomatopoeia_candidates.json` も参照する。

## 全体の流れ

```
入力文
  │
  ▼
語の抽出（Go本体のトークナイザ。表層形と読みを取り出す）
  │
  ├─ 第1段 動物レキシコン ──── 名前・鳴き声の直接一致
  │    例: 「ぶーぶー」(鳴き声) → ブタ
  │
  ├─ 第2段 JMdict擬音語 ────── on-mim 2,171語。glossが音の意味を説明
  │    例: 「にゃーにゃー」 = meow / cat → 猫
  │
  ├─ 第3段 ConceptNet 多hop探索 ── 全jaグラフを両方向にたどる（--hops 1〜3、既定2）
  │    例: 「寒い」←[HasProperty]-「北極」-[RelatedTo]→「白熊」 (hop2)
  │    ♪=音源あり27種 /（名前のみ）=音源なし動物。hopが低いほど優先
  │
  ├─ 第4段 WordNet同義語 ───── 同義語へ広げてConceptNetを再照会
  │    例: 「毛」→(同義語)→「羊毛」-[RelatedTo]→ 羊
  │
  └─ 第5段 Embedding ───────── 文全体の意味ベクトルで27動物と照合
       例: 「喉が渇いた」→ カエル score 4.50
  │
  ▼
最終判定（上の段ほど優先。第5段はしきい値未満ならハズレ候補）
```

## 各辞書の実体

| 段 | 辞書 | 実体 | 特徴 |
| --- | --- | --- | --- |
| 1 | 動物レキシコン | `assets/animal-lexicon.json` | 確実だが語彙の穴に弱い |
| 2 | JMdict | on-mim抽出JSON（2,171語） | 擬音の意味を説明できる。概念対応表は未生成 |
| 3 | ConceptNet | 全ja-jaグラフSQLite（25万エッジ） | 関係名と重みで経緯を説明できる。多hop対応 |
| 4 | WordNet | `wnja-2.0` 同義語SQLite（299万組） | 表記ゆれ・言い換えを吸収 |
| 5 | Embedding | ruri-v3-70m int8 + 偏り補正 | 何にでも答えるが経緯は「意味が近い」のみ |

## 統合候補リスト（新UI案のCLI版）

- 5段の候補を1本に統合して表示する。順序は「信頼群→群内スコア」の辞書式で、群は 直接一致 → JMdict → hop1 → hop2 → hop3 → WordNet同義語 → Embedding。
- 各候補に絵文字アイコン・♪（音源あり）・（名前のみ）・由来を付ける。アイコン列は将来のUIの並びのイメージ。
- 合成対象の欄は「1位が音源ありならその鳴き声。音源なしなら名前表示＋次順の♪で合成」という案を示す。クリックによる再合成はUI実装時の仕様。

## 表示の読み方

- `※かな変換で一致（本番未対応）`: 本番エンジンは表層形でしか引かないため落とすが、かな折りたたみをすれば一致した診断情報。エンジン改善の候補を示す。
- `（概念対応表は未生成）`: JMdictのglossまでは引けたが、動物・概念への対応付けが未実装であることを示す。
- 最終判定の第5段には、しきい値によるハズレ判定を導入する案がある。値は未確定。

## 動物の対象集合（第3段）

- 音源あり27種（レキシコン）に加え、「IsAで生物カテゴリへ繋がる概念」を名前のみの動物として機械抽出する。
- 下位語を10件以上持つ語（人・虫・鳥など）はカテゴリ語とみなして除外する。
- 手書きの動物リストは持たない。

## 既知の制約

- 第2段の対応表と第4段の調整は作業中で、数値比較の結論はまだ出ていない。
- 第3段の多hop探索と名前のみ動物は本番未実装。本番は現状1-hop・27種限定である。
- 語の抽出（形態素解析）は長音記号まわりで断片を出す弱点があり、改善課題として別管理。
- 本CLIは確認用でありGo本体の選定ロジックそのものではない。正は `services/zoovoice/association.go`。
